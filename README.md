# empresaPropia

Landing comercial responsive para los planes Presencia, Crecimiento y Evolución.

## Estructura prevista

- `index.html`: contenido semántico
- `assets/css/styles.css`: estilos y responsive
- `assets/js/main.js`: interacciones
- `assets/images/`: imágenes SVG propias

## Estado

Repositorio inicializado. Pendiente incorporar los archivos de la landing desde el paquete local `Landing_Premium_Sticky_Nav.zip`.

El formulario de contacto es demostrativo y no envía datos todavía.

## Biblioteca visual de módulos

Abrí [biblioteca-modulos/index.html](biblioteca-modulos/index.html) para ver 16 secciones y 48 propuestas en tres variantes: Simple, Media y Compleja. Todas las imágenes tienen 800 px de ancho. Servicios incluye las nuevas propuestas diferenciadas.

El catálogo funciona al abrir el HTML directamente o mediante un servidor estático. Las interacciones dibujadas dentro de las imágenes son referencias de diseño.
